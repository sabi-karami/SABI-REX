# ⬢ SABI-REX

**پنل اختصاصی مبتنی بر Marzban روی Railway — تیره، شیشه‌ای، نئونی و مخفی**

</div>

---

#### ویژگی‌ها
- **ورودی مخفی:** پنل فقط از آدرس `https://DOMAIN/<REX_PANEL_KEY>` باز می‌شود. بقیه‌ی آدرس‌ها یک سایت ساده‌ی nginx یا صفحه‌ی 404 معمولی نشان می‌دهند.
- **بدون اثر انگشت:** صفحه‌ی وضعیت، API، داکیومنت و فایل‌های ظاهر پنل بدون کلید قابل دیدن نیستند.
- **بدون admin/admin:** رمز اول از `REX_INIT_PASSWORD` خوانده می‌شود، یا یک رمز تصادفی ساخته و یک بار در لاگ دیپلوی چاپ می‌شود.
- **حالت اضطراری امن:** اگر تنظیمات وب خراب شود، پنل بسته می‌شود و محدودیت‌ها دور زده نمی‌شوند.
- **قالب Obsidian Neon:** رنگ زرشکی و فیروزه‌ای، شیشه‌ی مات، صفحه‌ی ورود متحرک و صفحه‌ی اشتراک REX PASS.
- **پنل نمایندگی**، **۱۲ کانفیگ**، **نگهبان خودکار** و **بکاپ روزانه** از نسخه‌ی پایه حفظ شده‌اند.

#### نصب روی Railway
1. این ریپو را Fork کنید و در Railway گزینه‌ی **Deploy from GitHub repo** را بزنید.
2. Region را روی **EU West (Amsterdam)** بگذارید.
3. یک Volume با مسیر `/var/lib/marzban` اضافه کنید.
4. یک دامنه با پورت `8080` بسازید.
5. متغیرهای `REX_PANEL_KEY`، `REX_INIT_PASSWORD` و (در صورت داشتن دامنه‌ی شخصی) `PANEL_DOMAIN` را تنظیم کنید.
6. Deploy کنید و پنل را از `https://DOMAIN/<REX_PANEL_KEY>` باز کنید.

ورود نماینده‌ها: `https://DOMAIN/<REX_PANEL_KEY>/agent`

#### متغیرها
همه‌ی متغیرها در [`variables.env`](variables.env) آمده‌اند. متغیرهای پیشرفته با پیشوند `REX_` شروع می‌شوند.

#### مجوز
بر پایه‌ی [Marzban](https://github.com/Gozargah/Marzban) (AGPL-3.0) و Xray-core.
